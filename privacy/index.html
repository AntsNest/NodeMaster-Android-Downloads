노드마스터의 기본 노트 기능은 회원가입 없이 기기에서 사용할 수 있습니다. 0.1.26부터 선택적으로 nodemaster.co.kr의 웹 계정·라이브러리·쪽지에 연결할 수 있습니다. 이 방침은 kr.co.antsnest.nodemaster 앱에 적용됩니다.

기기 내 저장

파일·탭·노드의 제목과 본문, 링크, 색상, 체크 상태, 사용자 속성, 앱 설정 및 저장 전 편집 이력은 앱 전용 기기 저장소에 보관합니다. 저장 전 이력은 파일별 최근 100개까지 유지합니다.

수집 및 전송

위치, 연락처, 광고·기기 식별자를 수집하지 않습니다. 광고·분석 SDK, 자동 동기화·자동 업로드와 Android 앱 데이터 자동 백업을 사용하지 않습니다. 웹 기능에 인터넷 권한을 사용하며, 사용자가 선택한 작업만 HTTPS로 nodemaster.co.kr에 요청합니다.

웹 계정과 노드 전송 (선택)

로그인할 때 입력한 계정과 비밀번호를 웹 서버에 전송합니다. 비밀번호는 앱에 저장하지 않습니다. 계정 표시 정보와 로그인 토큰은 Android Keystore 키로 암호화해 기기에 저장하며 로그아웃하면 삭제합니다. 업로드를 선택하면 해당 파일의 탭·노드·첨부 내용이 내 웹 계정에 저장됩니다. 쪽지 전송은 선택한 계정에 제목·본문·노드 사본을 전달하며, 첨부 사본은 내 웹 파일에도 남습니다. 라이브러리 공개는 선택한 탭과 하위 노드만 누구나 볼 수 있도록 공개합니다. 수신 계정 검색어와 라이브러리 검색어도 요청에 포함됩니다. 서버는 요청 처리 과정에서 IP 주소 등 접속 정보를 처리할 수 있습니다.

음성 입력 (선택)

사용자가 음성 입력을 시작할 때만 마이크 권한을 요청합니다. Android 12 이상에서 지원되는 기기 내 음성 서비스와 언어 모델을 이용합니다. 클라우드 음성 인식으로 전환하지 않습니다. 녹음 파일은 저장하지 않으며, 확인 후 추가한 텍스트는 일반 노트와 같은 기기 내 저장소에 보관됩니다. 창을 닫거나 앱이 배경으로 이동하면 인식을 중지합니다. 미지원 기기에서는 직접 입력할 수 있습니다.

파일 가져오기·내보내기

사용자가 시스템 파일 선택창에서 선택한 JSON을 가져오거나 지정한 위치로 내보냅니다. 클라우드 등 외부 파일 제공자를 직접 선택한 경우 해당 제공자의 방침이 적용됩니다. 다른 파일을 임의로 탐색하거나 자동 전송하지 않습니다.

보관 및 삭제

일반 삭제한 문서는 휴지통에서 복원할 수 있습니다. 수정 전 내용이 저장 이력에 남을 수 있습니다. 전체 내부 데이터는 Android 설정에서 앱 데이터 삭제를 실행하거나 앱을 제거하여 삭제합니다. 별도로 내보낸 JSON은 해당 저장 위치에서 직접 삭제해야 합니다. 앱 제거·데이터 초기화 전 중요한 문서를 내보내어 보관해 주세요. 앱 삭제와 로그아웃은 웹에 업로드한 파일·쪽지·공개 문서를 삭제하지 않습니다. 웹 데이터는 nodemaster.co.kr에서 관리하거나 아래 문의처로 삭제를 요청할 수 있습니다. 상대에게 전달한 사본은 상대의 보관 범위에 남을 수 있습니다.

보안

내부 데이터는 Android 앱 전용 저장소의 접근 제한으로 보호됩니다. 내보낸 파일의 보안과 공유 범위는 사용자가 선택한 보관 위치에 따라 달라집니다.

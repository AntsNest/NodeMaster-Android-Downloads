노드마스터 Android
개인정보처리방침

운영자: 주식회사 앤츠네스트 · 시행일: 2026년 10월 31일

노드마스터 Android는 회원가입 없이 사용하는 오프라인 노트 앱입니다. 노트와 편집 이력은 사용자 기기에 저장되며, 앱이 이를 운영자의 서버로 전송하지 않습니다.

1. 적용 범위

이 방침은 패키지 이름 kr.co.antsnest.nodemaster인 노드마스터 Android 앱에 적용됩니다. 앤츠네스트의 다른 웹사이트와 서비스에는 각 서비스의 방침이 적용됩니다.

2. 앱이 처리하는 데이터

사용자가 입력한 파일·탭·노드의 제목과 본문, 링크, 색상, 체크 상태, 사용자 속성, 앱 설정 및 저장 전 편집 이력을 앱 전용 기기 저장소에 보관합니다. 저장 전 이력은 파일별 최근 100개까지 유지됩니다.

앱은 계정 정보, 위치, 연락처, 광고 식별자, 기기 식별자를 수집하지 않습니다. 광고 SDK, 분석 SDK, 서버 동기화, 자동 업로드 기능이 없으며 Android 인터넷 권한을 요청하지 않습니다. Android의 앱 데이터 자동 백업도 사용하지 않습니다.

3. 파일 가져오기와 내보내기

가져오기는 사용자가 시스템 파일 선택창에서 직접 선택한 JSON 파일을 읽습니다. 내보내기는 사용자가 지정한 위치에 JSON을 저장합니다. 클라우드 저장소 등 외부 파일 제공자를 선택한 경우 해당 제공자의 데이터 처리에는 그 제공자의 방침이 적용됩니다. 앱이 다른 파일을 임의로 탐색하거나 자동 전송하지 않습니다.

4. 보관 및 삭제

일반 삭제한 문서는 앱의 휴지통에서 복원할 수 있습니다. 문서의 제목이나 본문을 수정해도 이전 내용이 저장 전 이력에 남을 수 있습니다. 앱의 전체 내부 데이터는 Android 설정에서 앱 저장공간의 데이터 삭제를 실행하거나 앱을 제거하여 삭제할 수 있습니다. 사용자가 별도로 내보낸 JSON 파일은 앱 삭제 후에도 남을 수 있으므로 해당 저장 위치에서 직접 삭제해야 합니다.

앱을 삭제하거나 데이터를 초기화하면 내부 문서를 복원할 수 없으므로 필요한 자료는 먼저 내보내어 보관해 주세요.

5. 제3자 제공 및 보안

운영자는 앱의 노트 데이터를 서버로 수집하거나 제3자에게 판매·제공하지 않습니다. 데이터는 Android 앱 전용 저장소의 접근 제한으로 보호됩니다. 사용자가 내보낸 파일의 보안과 공유 범위는 선택한 보관 위치에 따라 달라집니다.

앱의 데이터 처리 방식이 변경되는 경우 이 페이지와 앱 내 안내를 갱신하며 시행일을 표시합니다.
